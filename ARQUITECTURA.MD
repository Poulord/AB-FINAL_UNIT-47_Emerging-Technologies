# Arquitectura del proyecto

## Descripción general

Web profesional para Lily Flores Photography desarrollada con enfoque estático utilizando HTML, CSS y JavaScript. El proyecto se ha concebido como una presencia digital clara y estética, optimizada para imagen de marca y servicios fotográficos.

## Tecnologías

- HTML
- CSS
- JavaScript
- GitHub
- Vercel
- Outlook / correo
- Supabase (mejora futura)

## Estructura de carpetas

```
/
├── index.html
├── gallery.html
├── weddings.html
├── lifestyle.html
├── personal-brands.html
├── wellness-retreats.html
├── content-creation.html
├── contact.html
├── styles.css
├── script.js
├── vercel.json
└── img/
```

## Componentes principales

- `index.html`: página de inicio y presentación general.
- `gallery.html`: página de galería de imágenes.
- `weddings.html`: sección dedicada a fotografía de bodas.
- `lifestyle.html`: sección de lifestyle y retratos.
- `personal-brands.html`: servicios para marcas personales.
- `wellness-retreats.html`: servicios para retiros wellness.
- `content-creation.html`: servicios de creación de contenido.
- `contact.html`: formulario de contacto.
- `styles.css`: estilos globales y personalización visual.
- `script.js`: interacciones y lógica del front-end.
- `img/`: recursos e imágenes usadas en el sitio.

## Flujo de trabajo

1. Usuario accede al sitio web.
2. La web muestra contenido visual y secciones de servicio.
3. El usuario puede navegar por secciones y galerías.
4. El usuario envía una consulta a través del formulario de contacto.
5. El sitio se despliega en Vercel desde GitHub.

## Subagentes (concepto de apoyo)

- `Sagan`: estética / imágenes.
- `Carver`: responsive y adaptabilidad.
- `Descartes`: GitHub y control de versiones.
- `Jason`: Vercel y despliegue.

## Despliegue

La aplicación está preparada para desplegarse en Vercel y conectada al repositorio GitHub. `vercel.json` gestiona la configuración de despliegue.

## Mejoras futuras

- Integración con Supabase para backend y almacenamiento.
- Analítica de visitas y comportamiento.
- Optimización SEO y metadatos.
- Validaciones del formulario de contacto.
- Optimización de imágenes y rendimiento.

## Consideraciones de diseño

- Priorizar una experiencia visual elegante y minimalista.
- Mantener una estructura estática sencilla para facilitar el despliegue.
- Preparar el proyecto para añadir mejoras dinámicas sin rehacer la arquitectura básica.
